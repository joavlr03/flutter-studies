## 📂 Projects

| Folder | Description | Topics |
|---|---|---|
| [Appiadas](./Appiadas) | Shows a new joke every time the button is pressed. | Stateful widgets, state updates |
| [joken-pokemon-app](./joken-pokemon-app) | Pokémon battle simulator based on rock-paper-scissors. | Game logic, randomness |
| [pokemon-starter](./pokemon-starter) | Base structure for a Pokémon-themed app. | Project setup, widget tree |
| [quem_eh_esse_pokemon](./quem_eh_esse_pokemon) | "Who's that Pokémon?" quiz: guess the character from its silhouette. | Quiz flow, images |
| [sorting_app](./sorting_app) | Harry Potter themed app where the Sorting Hat picks your house. | Randomness, UI theming |
| [iron-man-key](./iron-man-key) | Iron Man themed strong password generator. | String generation, UI |
| [viacepserviceapp](./viacepserviceapp) | Finds the user's address from a CEP using the ViaCEP API. | REST API consumption, async |
| [easy_address_app](./easy_address_app) | Looks up addresses with the ViaCEP API and saves them in a list. | REST API, list state |
| [ludoboardgames](./ludoboardgames) | Board games catalog screen with mouse and touch scrolling. | Layout, lists |
| [flutter_frete_testes](./flutter_frete_testes) | Unit tests for a shipping (freight) calculation. | Unit testing |
